# NestHub 快捷收藏

适用于 Chrome、Microsoft Edge、Brave 等支持 Manifest V3 的 Chromium 浏览器，无需安装依赖或构建。

## 安装

1. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
2. 开启「开发者模式」，点击「加载已解压的扩展程序」。
3. 选择本 README 所在的 `extensions/nesthub` 目录。
4. 将「NestHub 快捷收藏」固定到浏览器工具栏。

## 使用

首次连接也可填写站点根地址，点击「使用网站登录状态连接」：在同一浏览器配置文件中打开并登录该 NestHub 网站后，扩展读取该站点的登录令牌并验证，无需手动复制。没有登录时会提示先登录；网站退出或令牌更换不会自动同步，需要重新连接。

插件支持 11 套中文主题（含樱糖、高级黑金、液态玻璃、经典目录、侧栏工作台与极简起始页）。连接站点后，切换主题会保存到当前账号的导航设置，同时同步插件、贴边按钮与已打开的同空间导航页。网站后端也需要更新到支持 `/api/site/theme` 的版本。

导航地址自动复用连接的站点，无需重复填写。开启「启动浏览器时打开导航」并保存，会优先复用空白新标签页；可额外开启「新标签页也打开导航」，之后新建标签页直接进入导航。首次开启需要标签页权限以识别空白页，已有正常网页不会被替换。点击「立即打开导航」可随时打开站点。

1. 打开要收藏的网页，点击扩展图标，或按 `Alt+Shift+B`（可在浏览器扩展快捷键设置中修改）。
2. 首次使用填写 NestHub 根地址和 API 令牌，授权访问此站点并验证连接。当前服务端支持 Bearer JWT，在网站后台「API 调用说明」点击「复制当前 JWT」获取；尚未提供独立的长期 API Key。
3. 扩展会自动填写当前页面标题、地址；选择分类，可选填描述、标签或勾选置顶。
4. 点击「添加到 NestHub」，出现收藏成功提示后即可关闭弹窗。

站点示例：`https://nav.example.com`。本机开发可使用 `http://localhost:5186` 或运行中的前端代理地址。远程站点必须使用 HTTPS，暂不支持部署在子路径下的站点。

默认保存到令牌所属账号的空间，超级管理员按门户返回的可编辑空间保存。当前没有分类时，请先在网站创建分类，再点击「刷新分类」。扩展记住上次使用的分类。浏览器内部页不能自动读取地址，可手动输入正常网页地址。

扩展只申请读取当前活动页、保存本地设置，以及用户明确授权的 NestHub 站点访问权限。插件不收集邮箱、密码。API 令牌仅保存在扩展本地存储并限制内容脚本访问。令牌无效或过期需更换，断开连接会清除令牌及分类记录，保留站点地址便于再次连接。

无需修改服务端跨域设置：扩展通过用户授权的站点权限访问现有 API。如果连接失败，请确认地址可访问、HTTPS 证书有效、站点根路径下存在 `/api/portal` 和 `/api/links`。浏览器弹窗关闭会中断尚未完成的操作，请等待成功提示；网络失败后可先到网站确认是否已保存，再重试。

此目录可用于本地加载。后台提供 Chrome 商店入口，是否可安装及版本以商店审核发布状态为准；目前不提供 Firefox 或 Safari 安装包。

## 快捷键无反应

`Alt+Shift+B` 是建议快捷键，浏览器不保证自动绑定（可能与其他扩展或系统快捷键冲突）。

1. 修改或更新插件后，在扩展管理页点击本扩展的「重新加载」按钮。
2. Chrome 打开 `chrome://extensions/shortcuts`；Edge 打开 `edge://extensions/shortcuts`。
3. 找到「NestHub 快捷收藏」的「打开 NestHub 快捷收藏」，确认是否已绑定；没有则手动录入 `Alt+Shift+B`，发生冲突则自行选用其他组合。
4. 切回普通网页测试。也可以直接点击工具栏上的扩展图标打开相同收藏窗口。

快捷键由浏览器管理，插件无法强制覆盖现有绑定。不要在扩展目录里直接打开 popup.html，必须通过已加载的扩展操作。

## 网页贴边收藏按钮

在插件设置中开启「在网页上显示贴边收藏按钮」，并允许访问 HTTP/HTTPS 网页。按钮使用简洁书签符号，默认出现在右侧，可拖动到左侧或右侧，位置跨网页保存。点击后在按钮附近展开网页内收藏面板，自动填入来源网页的地址和标题，不创建系统窗口或任务栏图标。再次点击可收起，也可点击面板关闭按钮、外部空白或按 Escape。面板使用独立扩展页面，令牌不会传给网页。在插件设置中关闭可全局停用。

贴边按钮默认关闭。浏览器内部页、扩展商店等受限制页面无法显示。更新插件后需重新加载插件并刷新网页。开启后需要网页访问权限；关闭会停止自动注入按钮，连接 NestHub 所需的站点权限保留。

## 1.2.0 更新说明

- 收藏窗口采用紧凑布局，描述和标签默认折叠，保存按钮滚动时保持可见。
- 贴边按钮更早加载，并使用浏览器顶层浮窗固定在可视区域，避免网页变换或裁剪影响显示。
- 统一图标、珊瑚红按钮、白色表单与操作提示。
- 后台提供 Chrome 商店入口与手动 ZIP 安装、覆盖更新步骤。

手动安装更新后，在扩展管理页重新加载插件并刷新已打开网页。商店版本需开发者上传本版并通过审核后才会自动更新。

## 1.3.1 修复说明

- 分类按站点和令牌保存在本地缓存，后续打开收藏窗口直接显示，不重复请求接口。点击「刷新分类」强制获取最新分类；修改分类后需手动刷新。切换连接、断开连接或令牌失效时清除缓存。

- 贴边按钮缩小至 36px 并紧贴边缘，移除悬停提示、浏览器原生提示和关闭图标；在插件设置中统一开关。

修复 Chrome 工具栏弹窗首次测量时宽度过窄的问题。窗口固定为 380 像素宽，标题、断开连接和保存按钮保持单行显示。

## 1.4.0 修复说明

- 连接验证成功后先保存配置，再显示成功；失败的新连接不会清除已有可用连接。未完成连接的地址和令牌草稿保存在受限制的本地存储中，成功后清除草稿。
- 连接与启动导航统一使用一个地址，支持直接输入域名或站点页面地址，自动提取站点根地址。
- 主题同步到当前账号的导航设置，桌面和手机主题一起更新，其他站点设置保持不变。
- 启动导航优先复用空白标签，增加新标签页打开导航选项，并防止并发事件重复打开。
- 收藏窗口改为紧凑布局，优化高级黑金配色、表单对比、按钮与次要信息层次。

## 1.4.1 稳定性修复

- 阻止连续点击重复提交收藏；收藏成功后，本地偏好保存失败不会误报收藏失败。
- 断开连接或更换连接后，旧分类刷新结果不会恢复过期会话。
- 令牌失效后保持收藏按钮禁用；校验异常分类缓存并重新读取。
- 悬浮按钮脚本注册串行执行，避免多个事件同时注册失败。
- 启动导航按窗口处理，清理重定向状态，并容错无效的旧地址。

手动更新时覆盖解压到原目录，在扩展管理页点击重新加载，再刷新已打开网页。

## 1.4.2 使用调整

- 收藏、主题与设置采用紧凑的分页界面，底部操作区域固定。
- 设置先调整，最后统一保存，并在保存时申请所需权限。
- 包含樱糖在内的 11 套中文主题，可与导航站点同步。

网站更新不会自动升级手动安装的插件。下载新 ZIP 后覆盖原解压目录，重新加载扩展并刷新网页；商店版按审核发布版本更新。

## 1.4.3 网页内收藏面板

- 贴边按钮使用简洁书签符号，点击在网页内展开，移除独立系统窗口。
- 同一页面只保留一个面板，重复点击收起，避免任务栏不断新增窗口。
- 面板沿用插件收藏、主题与设置界面，支持关闭与小屏尺寸限制。

更新后需重新加载扩展并刷新原网页。旧版本已打开的独立窗口需手动关闭。

# NestHub 1.4.0

## 界面与主题
- 精调十套主题的背景、侧栏、卡片、搜索、按钮、页脚和弹窗配色，统一明暗模式与手机端表现。
- 经典主题在网站、后台和插件中均排在第一位；主题提供中文名称与说明。
- 去掉青柠主题占空间的通用介绍；后台统一为清爽的管理工作台。
- 图标字体随网站打包，不再依赖外部 CDN。

## 插件与站点
- 修复插件连接保存不稳定，失败连接保留原配置，分类缓存可手动刷新。
- 连接地址与导航地址合并；插件切换主题同步更新导航站的桌面与手机主题。
- 启动导航复用空白标签，避免多开；支持可选的新标签页导航。
- 网页收藏按钮更紧凑、更贴边，收藏窗口靠近点击位置显示。
- 外部站点图标通过服务器获取，认证失败时使用备用图标，避免浏览器弹出认证框。

## Docker 更新
- 一个 Compose 文件同时部署网站及更新服务，部署后可在后台点击更新。
- 提供 SQLite 与 MySQL 两种示例，目录挂载说明见部署文档。
- 镜像构建时自动打包当前插件，后台可以下载同版插件。

## 升级步骤
1. 保留原有 `data/app`（以及 MySQL 部署的数据库目录）和原有 JWT、数据库配置。
2. 使用新版 Compose 示例，在 `.env` 增加随机长字符串 `UPDATE_API_TOKEN`，首次升级运行 `docker compose up -d`。
3. 固定版本可使用 `ghcr.io/sunnyfancore/nesthub:1.4.0`；希望后台持续更新请使用 `latest`。
4. 手动安装插件时解压新 ZIP，在扩展管理页重新加载并刷新网页。启用启动或新标签页导航时，保存一次插件设置并授权。

Chrome 商店版本仍需单独上传审核，本次 GitHub 发布不代表商店已更新。

# NestHub 快捷收藏隐私政策

最后更新：2026 年 10 月 10 日

本政策适用于「NestHub 快捷收藏」浏览器扩展。该扩展用于将用户选择的网页保存到用户自行部署或自行选择的 NestHub 服务，不提供统一的云端书签托管服务。

## 处理的数据及用途

- **网站地址和标题**：用户打开收藏窗口时，扩展读取当前网页（或触发浮窗的来源网页）的 URL 和标题，自动填入收藏表单。用户可修改这些信息；只有点击保存时，才将收藏信息发送到用户配置的 NestHub 服务。
- **用户填写的收藏信息**：分类、描述、标签和置顶设置用于创建用户请求的收藏记录，并随保存请求发送到用户配置的 NestHub 服务。
- **身份验证信息**：用户输入的 API 令牌用于通过 `Authorization: Bearer` 请求头向用户配置的 NestHub 服务验证权限。用户也可主动点击「使用网站登录状态连接」，授权扩展读取指定站点已打开页面本地存储中的 `nesthub.token`，验证后保存在扩展中。仅访问用户指定的站点，不读取其他网站的登录信息或浏览器密码。扩展不要求输入 NestHub 账号邮箱或密码。
- **本地设置**：扩展在浏览器的扩展本地存储中保存站点地址、API 令牌、分类缓存、最近使用的分类、主题、浮窗开关和位置、启动导航开关及地址，以恢复连接和显示偏好。令牌存储访问限制为扩展的受信任上下文，不向注入网页的浮窗脚本提供令牌。启动导航默认关闭，开启后在浏览器启动时访问用户配置的导航地址。
- **服务返回的数据**：扩展读取 NestHub 门户 API 返回的空间、分类及相关门户数据，以确定收藏目标并显示分类。服务返回的原有链接不是由扩展重新采集的浏览记录。

## 网页访问和可选浮窗

连接服务时，扩展申请访问用户明确输入的 NestHub 站点。贴边收藏浮窗默认关闭；用户主动开启并授权后，扩展在允许的 HTTP/HTTPS 网页中注入本地浮窗脚本，显示、移动或关闭收藏入口。浏览器受限制的页面无法显示浮窗。

浮窗不会读取网页正文、表单内容、密码或键盘输入，不会记录完整浏览历史，也不会自动上传用户访问的网页。拖动时的位置仅用于保存浮窗显示偏好。用户打开收藏窗口时会读取来源页 URL 和标题，保存仍需用户点击确认。

## 数据传输及共享

扩展仅向用户配置的 NestHub 服务发送必要 API 请求，包括通过令牌读取门户信息及保存用户确认的收藏。远程服务连接要求 HTTPS；本机开发允许通过 localhost、127.0.0.1 或 ::1 使用 HTTP。

本扩展不包含广告、第三方统计或跟踪 SDK，不出售用户数据，不将数据用于广告、信用评估或与收藏功能无关的用途，也不向开发者的统一分析服务发送数据。所有可执行代码包含在扩展包中，不下载或执行远程代码。

用户选择的 NestHub 服务由相应服务运营者管理。已保存书签的存储、访问权限、服务器日志、备份及保留期限由该运营者的配置和政策决定；本扩展不能控制远程服务对数据的处理。请仅连接可信服务。

## 保存、删除和用户控制

- API 令牌和设置保存于浏览器本地，不使用 Chrome 同步存储。
- 点击「断开连接」会清除保存的连接令牌及最近分类，保留站点地址和浮窗偏好。令牌失效时也会清除连接信息。
- 取消勾选浮窗开关会停止自动注入按钮；关闭浮窗不会自动撤销已授权的站点权限。用户可在浏览器扩展设置中管理访问权限，或卸载扩展以删除浏览器保存的扩展本地数据。
- 已发送到 NestHub 服务的收藏不会因断开连接或卸载扩展自动删除；请通过该服务管理页面删除，并向其运营者了解日志及备份保留规则。
- 不建议收藏带有敏感凭据或私人参数的地址；保存前可在表单中修改地址。

## 政策更新及联系

功能或数据处理方式变化时，本政策将随项目更新，并注明更新日期。

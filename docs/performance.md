# 性能与资源优化

本轮保留 .NET 后端和现有功能，优先减少实际加载与数据库分配，不设置未经验证的内存硬上限。

## 前端

- Element Plus 按组件引入，保留中文语言配置、消息提示和确认弹窗。
- 登录、分类编辑、链接编辑、站点设置、关于弹窗只有打开时才加载并挂载。
- 拖拽模块仅在可编辑视图加载；拖拽实例不进入 Vue 深度响应式代理。
- 页面卸载时清理搜索防抖，避免未完成的加载重新注册监听器和拖拽实例。
- Font Awesome 图标字体随站点发布，只保留现代浏览器使用的 WOFF2，无需连接外部字体 CDN。
- JS/CSS 支持 Brotli 和 gzip，使用低 CPU 开销的压缩级别，保留带哈希资源的长期缓存。API、上传文件、插件 ZIP 和健康检查不进入压缩分支。
- 经典主题采用静态 CSS 网格背景，不引入 canvas、额外图片、动画计时器或全屏模糊。

## 后端

- 点击书签只执行一条原子计数更新，避免读出完整书签、回写所有字段；并发点击不会互相覆盖，也不会覆盖同时发生的标题或网址编辑。
- 超级管理员的租户链接数量由数据库 GROUP BY 汇总，不再将每条书签的租户编号加载到内存分组。
- 书签增加租户/分类组合索引，分类增加租户/父分类组合索引。开启结构同步的现有部署会自动创建；首次创建耗时随数据库规模变化。
- 保留有上限的图标缓存和网络请求并发限制，不缓存混合不同租户权限的页面响应。

## 本地对比与验证

Windows / Edge 同一组示例书签、只读经典主题首页，生产构建、全新浏览器上下文：

| 项目 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 首屏站内 JS/CSS 未压缩总量 | 1,623 KB | 607 KB |
| 页面脚本堆单次采样 | 5.5 MB | 4.1 MB |

JS/CSS 约减少 63%。上述统计不包含图标字体和浏览器自身内存，也不是服务器内存或线上耗时保证；首屏请求被拆分为较小资源，后续使用浏览器缓存。打开编辑器与进入后台会按需加载对应资源。

已验证生产构建、26 个后台布局场景、经典主题 390/1440/1920 宽度和深色模式、大屏四列、按需弹窗、并发点击计数、数据库分组统计、Brotli/gzip 与缓存响应头。真实服务器 CPU/内存和并发吞吐仍应在部署环境中测量。

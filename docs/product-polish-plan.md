# NestHub 整站精修规划

本轮目标：统一基础尺寸、内容层级和交互反馈，保留 11 个主题的配色、菜单特点和已有动效。覆盖网站首页、后台公共组件及移动端；不修改插件、数据库和更新部署机制。发布与推送另行确认。

## 实施清单

1. 品牌与导航：统一 Logo 区高度及留白，兼容整图与文字；根菜单与子分类层级清晰，长名称省略并提供完整标题，键盘焦点可见。
2. 首页内容：卡片标题与域名保持清晰层级，分类长标题可换行；子分类按钮支持长名称，手机点击区域至少 44px；不改变桌面最多四列和居中布局。
3. 搜索及浮层：搜索框提供明确标签及焦点反馈；引擎菜单、建议和右键菜单使用不透明主题表面，列表可滚动但不越出短屏；Escape 关闭页面浮层并恢复菜单入口焦点。
4. 提示与页脚：空态、错误提示、加载层保持主题一致；长网址及页脚内容不撑开页面，移动端弹窗与底部安全区域协调。
5. 后台：统一表单焦点、按钮及表格工具区的密度；移动端菜单、分页与弹窗操作至少 44px，表格保持自身滚动；侧栏支持 Escape 关闭和焦点返回。
6. 性能与动效：新增样式不引入图片、依赖或持续动画；尊重减少动画设置；不改变图标获取流程。

## 验收

- 前端类型检查与生产构建通过。
- 11 个主题的明暗模式、窄屏与大屏无水平溢出，顶部和弹窗无背景穿透。
- 11 个主题的桌面/移动 Logo 布局一致，根菜单和子分类可操作。
- 搜索、长文字、Escape、空态/错误状态与后台移动菜单做场景验证。
- 后台代表页面：概览、分类、链接、站点设置、主题、更新；检查 390px 和桌面布局。

## 边界

本轮是统一体验打磨，不重做配色、不增加主题、不修改插件或服务器。真实服务器更新和浏览器商店发布不在本轮验证范围内。

## 第四轮：快速操作与请求顺序（2026-10-11）

- 搜索输入变化时立即隐藏旧建议；清空、Escape、切换公共/个人视图及离开页面时使旧请求失效。迟到的结果不会覆盖新关键词或重新弹出已关闭的列表。
- 中文输入法组词期间不请求建议，确认候选词的 Enter 不触发外部搜索。
- 后台链接及分类查询只接受最新请求，旧请求不更改列表/加载状态、不显示过期错误；页面卸载使未完成请求失效。
- 三种编辑表单增加校验中的提交锁，防止快速连点；无效表单及已关闭弹窗不发出提交事件。
- 验证：生产构建通过；模拟旧搜索/链接/分类响应最后返回，清空及 Escape 后返回、中文输入法 Enter、分类请求在离开页面后失败、分类保存连点等场景通过。接口使用本地模拟数据，没有修改服务器数据。

本轮修改未推送，插件未改动。

## 第五轮：失败恢复与设置保护（2026-10-11）

- 增加后台共用的读取失败提示和重新加载按钮；分类/链接读取失败与真正空列表分开显示。
- 链接及分类选项并行加载，分类失败不再阻断链接列表；选项尚未成功读取时禁止新建/编辑，恢复后解除限制。公共/个人管理页切换时清掉旧空间的列表与分类状态。
- 站点和主题设置读取成功前不显示可编辑表单、不允许保存，避免空默认值覆盖配置；站点读取请求支持顺序和卸载保护。
- 设置/链接保存失败时保留草稿供重试；后台提交增加进行中保护。取消删除、取消重置排序正常返回，不产生未处理异常。
- 验证：生产构建通过；模拟设置读取失败后重试恢复、主题读取失败时隐藏保存入口、分类选项失败但链接仍显示、站点及链接保存失败保留草稿、取消删除/重置等场景通过；上一轮请求顺序和单次提交回归仍通过。未触碰真实服务器数据。

第五轮仍未推送，插件未改动。

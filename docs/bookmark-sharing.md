# 书签分享

在后台「书签分享」选择分类并创建链接。分享包含该分类及子分类的书签，内容随原分类更新；不会提供后台管理权限，也不会返回内部备注、备用地址或访问统计。

默认有效期为 7 天，也可设置未来的过期时间或明确选择长期有效。链接使用 256 位随机访问令牌；无密码的链接允许持有链接的人访问。敏感分类请设置至少 6 位的独立访问密码，并通过 HTTPS 访问站点。

密码只保存哈希，创建后无法查看或找回。复制链接不会复制密码，需要另行告知接收者。忘记密码时撤销旧分享，重新创建。

到期、撤销、分类删除或所属空间停用后，后续访问会被拒绝。撤销无法收回接收者已经下载、复制或截取的内容。分享页不加载远程站点图标，外链不发送分享页来源信息，并提示搜索引擎不要索引；这些措施不能替代访问密码。

公开接口按连接 IP 限制为每分钟 20 次请求（页面信息和读取内容合计），超限后等待约一分钟。反向代理没有配置可信客户端 IP 时，多个用户可能共用代理 IP 的额度。

## 从旧版本升级

升级前备份数据库。正常开启 `Database__AutoSyncStructure=true` 时，启动会补齐分享字段，把旧明文密码转换为哈希，并生成新的访问令牌。旧短链接不再使用，请在后台重新复制分享地址；原分类、过期时间与记录保持不变。

关闭自动结构同步的部署必须先完成对应数据库结构迁移：为分享表增加可空的 `AccessToken`（64 字符）、`PasswordHash`（256 字符），并为 `AccessToken` 建立唯一索引。备份中的旧明文密码仍属于敏感信息，请妥善保管。
